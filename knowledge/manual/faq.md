# Preguntas frecuentes del curso, con respuesta

Resumen del `Media Buyers FAQ.md` (recurso de la sesión 6; `Recursos/FAQ.txt` es una copia
anterior). Cada respuesta está desarrollada en la nota del manual que se indica. Fuente de todas:
`[CURSO S6 · FAQ]`.

| Pregunta | Respuesta corta | Nota |
|---|---|---|
| ¿Presupuesto diario para empezar? | $10/día para la mayoría; el Protocolo lo afina | `presupuesto.md` |
| ¿Video o imagen? | Video casi siempre; una imagen con muy buen texto puede funcionar; test | `creativos.md` |
| ¿Forma más rápida de generar leads desde cero? | Reel de 60–90 s, texto con «mándeme un mensaje», Boost desde desktop, $10/día: 5–10 leads/día en LatAm a $1–2 por mensaje | `campanas.md` |
| ¿Boost o Business Manager? | Boost para empezar (video <90 s); Business Manager cuando ya funciona, para más ads o videos más largos | `campanas.md` |
| ¿Proceso de ventas para empezar? | Ad → DM → llamada → cierre | `funnels.md` |
| ¿WhatsApp o Instagram? | Los dos; test; Instagram solo si el perfil suma, si no, WhatsApp | `campanas.md` |
| ¿Objetivo para mensajes / para funnel? | Boost: Send Messages / Website. BM: Leads + Instagram; Traffic → Messaging Apps → WhatsApp; Leads para funnel | `campanas.md` |
| ¿Intereses o Suggested Audience? | Sin intereses o Suggested Audience, sobre todo con copy específico u oferta mass appeal; intereses solo como split test | `campanas.md` |
| ¿Género y edad? | Sí, según el avatar, y además dicho en el video; con mass appeal puede ir 100 % broad | `campanas.md` |
| ¿Países? | Sí; uno para empezar; el del acento de quien habla, salvo economía muy mala; mejores en español: México, Costa Rica, Colombia, España | `diagnostico-y-oferta.md` |
| ¿Texto del ad? ¿Ad copy base? | Documentos done-for-you de Sebastián (enlaces de Drive en el FAQ; no están en el curso descargado) | `copy.md` |
| ¿Cuánto invertir en total? | El precio de la oferta | `presupuesto.md` |
| ¿Cuándo subir presupuesto? | Con ROI+; $10 → 20 → 30 → 40 → 50 → 100; con leads sin ventas, esperar la primera venta | `presupuesto.md` |
| ¿Ads activos que no gastan? | Esperar 24 h; recrear la campaña; si no, problema de cuenta | `campanas.md` |
| ¿Muchos clicks, pocos leads? | Revisar que el objetivo no sea Traffic; con objetivo correcto, 7 días sin leads o costo muy alto = mal ad | `campanas.md` |
| ¿Mensajes que no contestan el template? | Normal un %; probar respuestas distintas, un audio corto; cambiar IG ↔ WA; «money in, money out» | `chat-y-llamada.md` |
| ¿Cuánto tiempo dejar un ad? | No por tiempo: por resultados relativos al gasto y al precio | `presupuesto.md` |
| ¿Variantes en bulk con clientes lentos? | A veces sí; que sean distintas entre sí | `campanas.md` |
| ¿Directo al funnel? | Funciona pero es avanzado; mejor ad → mensaje → llamada/funnel/link | `funnels.md` |
| ¿Real estate? | Ad (mini tour de 90 s) → WhatsApp → datos → cita | `funnels.md` |
| ¿Por qué el cliente sigue pagando? | Los ads tienen vida útil (1–6 meses); siempre hay que probar nuevos | `servicio.md` |
| ¿Cuánto cobrar? | $500–1.000/mes + 10–20 % de ventas; rev share primero o retainer primero | `servicio.md` |
